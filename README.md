# xiangqi-wuzi-chess
A offline board game including Chinese Chess, International Chess and Gomoku.leaving a functional imperfections.
## 项目简介
这是一个简易网页棋类小合集，包含中国象棋、国际象棋、五子棋。
使用 HTML 编写，**仅支持本地双人对战，没有内置AI对手**。

项目的大部分逻辑、规则判断、页面交互由AI辅助编写与调试，我主要负责整合代码、修改样式、测试问题。
存在不少不完善的地方，仅供学习把玩。

## 运行方式
直接打开对应的HTML文件即可，无需安装依赖，浏览器直接运行。

## 现存不足
- 中国象棋：未实现长将长捉等规则
- 国际象棋：缺少王车易位、兵升变等进阶规则
- 五子棋：完整禁手逻辑没有实现
